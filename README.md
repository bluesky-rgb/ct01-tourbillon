## CT-01 陀飞轮万年历

一块完全用代码造出来的 3D 机械表：双轴飞行陀飞轮、万年历、月相、自动上链摆陀，200 多个零件按真实齿比联动，表针显示此刻的真实时间。

整个页面就是一个 `index.html`（Three.js r128），没有构建步骤。

### 能做什么

- 外观 / 表盘 / 背面 / 陀飞轮特写 / 逐层拆开
- 定制：表壳（玫瑰金、铂金、黄金）× 表盘（银白、午夜蓝、黑曜石）× 表带（黑、干邑棕、海军蓝）
- 拧表冠调时间：拔出表冠、摆轮停摆，拖动拨时间，日历和月相跟着走
- 一键讲解：12 步，带配音和背景音乐，讲解中可自由拖动、暂停、跳步

### 目录

| 路径 | 说明 |
| --- | --- |
| `index.html` | 页面本体 |
| `music_bed.mp3` | 背景音乐：96 秒无缝循环的轻氛围音，由 `audio/make_bed.py` 合成 |
| `audio/narration.json` | 讲解配音文案（14 段，第 11 步分 a/b/c 三段） |
| `audio/gen_voice.py` | 调用 MiniMax 生成配音（`speech-2.6-hd`，音色 `Chinese (Mandarin)_Gentleman`） |
| `narration/` | 生成好的配音 `<id>.mp3` 和指纹 `manifest.json` |
| `.github/workflows/voice.yml` | 改了文案就自动重新生成配音 |

### 配音是怎么生成的

在仓库 Settings → Secrets and variables → Actions 里：

- Secret `MINIMAX_API_KEY`：必填
- Variable `MINIMAX_URL`：海外账号填 `https://api.minimax.io/v1/t2a_v2`，国内账号不用填
- 可选 Variable：`MINIMAX_VOICE`、`MINIMAX_MODEL`、`MINIMAX_SPEED`

之后只要修改 `audio/narration.json` 或 `apron/audio/narration.json` 并推送，GitHub Actions 就会只重新生成改动过的段落，并把 mp3 提交回 `narration/`。也可以在 Actions 页面手动运行「生成 MiniMax 配音」。

页面只播放 `index.html` 里 `VO` 列表登记过的配音；没登记的段落会退回浏览器自带语音。

### 本地预览

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

（需要用本地服务器打开，直接双击 `index.html` 时浏览器会拦截音频文件的读取。）

## 机坪俯瞰

照着一张机场停机坪的航拍照片重建：照片上每 10 像素对应场景里 1 个单位，飞机机头机尾、登机桥、地勤车辆、红色禁停区和黄色引导线都按原图像素位置摆放，阳光方向也按照片里的影子校准。

### 能做什么

- 航拍 / 自由 / 机位特写 / 地面四种视角，拆层看航站楼、登机桥、客机、车辆、标线、地面
- 白天 / 黄昏 / 夜晚：夜里高杆灯、候机楼窗户、地面绿色引导灯和飞机客舱舷窗都会亮起
- 中间机位完整过站流程（约 45 分钟，压缩到 1 分钟左右播放）：
  进港滑行（引导员挥棒、停靠引导屏倒数距离）→ 轮挡 → 靠桥 → 地面电源 → 下客 → 行李卸装（传送带上行李在动）→ 配餐车剪式升降 → 加油 → 客舱清洁 → 登机 → 撤桥 → 推出 → 发动机启动 → 离港滑行，然后下一架进港
- 右侧甘特图实时显示每项作业的进度和舱内旅客数，点任意一行可直接跳过去
- 点任意物体看它的名称
- 舱门：每架飞机都有立体的客舱门和右侧货舱门。中间那架靠桥后前舱门向外推出、贴着机身往前滑开；配餐车在右侧升到位后打开右后舱门（和真实机场一样，左侧留给旅客、右侧做服务）；行李车到位后后货舱门向上掀起，作业结束再依次关上
- 动作细节：车轮按行驶距离转动、转弯时前轮打方向；下客和登机时能透过登机桥玻璃看到旅客走过；地勤人员走进走出，推出时翼尖引导员举手示意
- 一键讲解：10 段镜头跟着过站流程运镜，MiniMax 配音（文案在 `apron/audio/narration.json`，音频在 `apron/narration/`），配背景音乐，讲解中可以拖动、暂停、跳段
- 画面：翼型截面的机翼和尾翼、襟翼滑轨整流罩、接触阴影、随昼夜变化的天空和大气雾

三架飞机都使用通用涂装，没有照搬照片里的航空公司标识。按照片里的翼展换算（1 个单位约 1.3 米），中间和右边是 A319 / A320 级窄体机，左边是 757 级加长窄体机：前者主轮装在翼根下、双轮，后者发动机更大、主起落架是四轮小车、翼尖是融合式小翼。登机桥按各自飞机前舱门的位置和门槛高度对接。
