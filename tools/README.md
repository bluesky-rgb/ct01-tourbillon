# tools

`clip-probe.js`：机坪场景的穿模检测脚本。把它插到 `apron/index.html` 的渲染循环之前（同一个作用域里），在浏览器控制台运行：

```js
__probe([0, .5, 1, /* … */ 45.5])  // 逐个时刻拨动过站时钟，检查所有移动车辆和人员
__probe([])                          // 检查静止车辆，以及路面上行驶的行李车队和摆渡车
```

原理：从每个车辆模型上取样顶点，沿两个方向发射射线，与飞机、登机桥、航站楼和其他车辆求交；交点数为奇数说明该点落在对方模型内部。

检测是双向的：除了检查车辆的点是否落进飞机，还会反过来检查飞机的点是否落进车辆。像水平尾翼、翼尖这种很薄的部件，可能整片切进车厢，而车厢的角点一个都不在尾翼里面，只做单向检测会漏掉。返回每一处穿模的时刻、双方名称和穿入的点数，反向检测到的会标注“（反向）”。
