# tools

`clip-probe.js`：机坪场景的穿模检测脚本。把它插到 `apron/index.html` 的渲染循环之前（同一个作用域里），在浏览器控制台运行：

```js
__probe([0, .5, 1, /* … */ 45.5])  // 逐个时刻拨动过站时钟，检查所有移动车辆和人员
__probe([])                          // 检查静止车辆，以及路面上行驶的行李车队
__trainSim(1, -40, 0)                // 逐帧模拟路面车队：速度、起点 x、起始过站时刻；返回碰撞次数和停车让行的帧数
__jumpTest()                         // 把过站时钟跳到任意时刻、车队放在任意位置，检查车队会不会停在被占用的路段里
```

原理：从每个车辆模型上取样顶点，沿两个方向发射射线，与飞机、登机桥、航站楼和其他车辆求交；交点数为奇数说明该点落在对方模型内部。

检测是双向的：除了检查车辆的点是否落进飞机，还会反过来检查飞机的点是否落进车辆。像水平尾翼、翼尖这种很薄的部件，可能整片切进车厢，而车厢的角点一个都不在尾翼里面，只做单向检测会漏掉。返回每一处穿模的时刻、双方名称和穿入的点数，反向检测到的会标注“（反向）”。

路面车队的让行规则：页面加载时，把过站流程从头到尾逐帧拨一遍，记录每辆会横穿车道的车（配餐车、行李车队、推出牵引车）以及进港、推出飞机的起落架和发动机，在什么时间段占用了车道的哪一段。车队行驶时，如果前方 6 个单位内有一段在接下来一小段时间里会被占用，就停车等待；如果时钟被跳转后车队恰好停在被占用的路段上，就把它移到这段路之前。
